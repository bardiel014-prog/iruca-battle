# 紅月闘技会

公開先: https://iruca.tech/battle/

2026-11-24時点の公開版から独立させたソースリポジトリです。リポジトリへのpushだけでは本番は更新されません。

## ローカルで画面を開く

```sh
python -m http.server 8000 --directory public
```

`http://localhost:8000/` を開いてください。このコマンドは画面の確認用で、通信対戦・集計APIは別途必要です。

## 通信対戦・解析

`backend/friend-api.php` と `backend/stats-api.php` は現在のサーバー処理です。PHP 8.3環境で、公開パス `/battle/friend-api`・`/battle/stats-api` に対応させます。ソース内のOriginチェックは本番ドメイン用です。別ドメインに配備する場合は変更してください。

保存ディレクトリはPHP内の設定に従い、公開ディレクトリの外に作成してください。集計閲覧には別途認証が必要です。本番の利用者データや認証設定は含めていません。

## 公開物の範囲

ゲームコードと必要な画像・音声を収録しています。本番の部屋データ、アクセスログ、集計結果、認証情報、非公開運用文書は含みません。

ソース・画像・音声の再利用許諾を新たに付与するものではありません。ライセンスは別途定めるまで未設定です。
